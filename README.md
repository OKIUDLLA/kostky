# kostky

Jednoduché počítadlo skóre pro dva hráče (hra v kostky).

## Použití

Otevři `index.html` v prohlížeči.

## Pravidla

- **Dva hráči** s vlastním skóre.
- **Cílová hodnota** je nastavitelná, minimum je **350**. Kdo první dosáhne cíle, vyhrává.
- Lze zapsat libovolný počet bodů včetně **0**.
- Když hráč zapíše **tři nuly po sobě**, počítá se to jako **absolutní nula** – skóre hráče se vynuluje a začíná od nuly.
